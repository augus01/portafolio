# Logo

El logo "apinto" y su monograma "ap" en SVG, solo en blanco o negro.

## Propiedades

`variant: 'logotype'* | 'monogram'` · `tone: 'dark'* | 'light'` · `height: number` (32*) · `label: string` ('Augusto Pinto'*) · `decorative?: boolean` · `className?`

`*` marca el valor por defecto.

## Teclado y accesibilidad

Por defecto es `role="img"` con `aria-label`. Con `decorative` se oculta, para cuando el nombre ya está escrito al lado.

## Uso

`dark` sobre superficies claras, `light` sobre `surface-inverse`. Alto mínimo 24px (logotipo) y 20px (monograma). No se recolorea, no se estira y no se pone sobre fotos. Los archivos sueltos están en el grupo de assets Logo.
