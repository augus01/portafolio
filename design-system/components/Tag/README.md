# Tag

Etiqueta informativa en mono y mayúsculas para tecnologías, estados o disponibilidad; no es interactiva.

## Propiedades

`children` · `variant: 'default'* | 'inverse'` · `size: 'sm' | 'md'*` · `title?: string` · `className?`

`*` marca el valor por defecto.

## Teclado y accesibilidad

Es un `<span>`; en grupos va dentro de una lista (`<ul>`) para que se anuncie la cantidad.

## Uso

Nombres cortos de tecnología, el estado de un proyecto o la disponibilidad en el Hero. No inventes niveles ni porcentajes. Si necesita acción, es un `Button` o un `Link`.
