# SectionHeadline

Encabezado de sección: antetítulo mono, título en display y párrafo de entrada.

## Propiedades

`title: string` · `eyebrow?` · `lead?` · `id?` · `as: 'h1' | 'h2'* | 'h3'` · `onDark?` · `className?`

`*` marca el valor por defecto.

## Teclado y accesibilidad

El título es un encabezado real (`h2` por defecto) y el `id` sirve como ancla para la navegación.

## Uso

Abre cada sección (Sobre mí, Superpoderes técnicos, Proyectos, Contacto). Título de máximo ocho palabras; el `lead` explica en una o dos frases.
