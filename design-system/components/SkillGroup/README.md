# SkillGroup

Grupo de tecnologías bajo un título, para la sección Superpoderes técnicos.

## Propiedades

`title: string` · `skills: string[]` · `description?: string` · `className?`

## Teclado y accesibilidad

Es una `<section>` nombrada por su título (`aria-labelledby`), con las tecnologías en una lista.

## Uso

Agrupa por área (Backend, Frontend, Cloud e IA). Sin barras de nivel ni porcentajes inventados; si quieres matizar, usa `description`.
