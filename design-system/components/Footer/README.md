# Footer

Pie de página oscuro con logo blanco, enlaces sociales y nota final.

## Propiedades

`links?: { label, href }[]` · `note: string` ('Hecho en Chile'*) · `year: string` (año actual*) · `className?`

`*` marca el valor por defecto.

## Teclado y accesibilidad

Es un `<footer>` con el logo como imagen nombrada y los enlaces de `SocialLinks`.

## Uso

Cierra todas las páginas. Se apila en contenedores de menos de 720px.
