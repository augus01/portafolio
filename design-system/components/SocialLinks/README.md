# SocialLinks

Lista de enlaces a GitHub, LinkedIn y correo, en fila o columna.

## Propiedades

`items: { label, href }[]` · `layout: 'row'* | 'column'` · `onDark?` · `className?`

`*` marca el valor por defecto.

## Teclado y accesibilidad

Es una `<ul>` de `Link`. Los externos abren en otra pestaña y lo anuncian; `mailto:` no.

## Uso

Texto, no iconos de marca: el sistema no usa logos de terceros.
