# StoryTimeline

Recorrido en pocos hitos para la sección Sobre mí: periodo a la izquierda, título y detalle a la derecha.

## Propiedades

`items: { period, title, description? }[]` · `className?`

## Teclado y accesibilidad

Es una lista ordenada (`<ol>`), así que se anuncia el orden y la cantidad.

## Uso

Tres a cinco hitos. Periodos en palabras ("Hoy", "Lo que sigue") o fechas reales. En contenedores angostos se apila.
