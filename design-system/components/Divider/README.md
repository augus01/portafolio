# Divider

Línea de 1px para separar bloques, horizontal o vertical.

## Propiedades

`orientation: 'horizontal'* | 'vertical'` · `onDark?: boolean` · `className?`

`*` marca el valor por defecto.

## Teclado y accesibilidad

Es un `<hr>` con `aria-orientation`. Es decorativo: no reemplaza un título de sección.

## Uso

Úsalo con moderación: el espacio (`space-*`) separa mejor que una línea.
