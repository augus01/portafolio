# Contexto

## Producto

Portafolio personal de Augusto Pinto, cuarto año de Ingeniería Civil Informática en la Universidad San Sebastián (Chile), con meta de convertirse en AI Engineer. Se construye para el reto de portafolio del hackathon de AWS Skill Builder y se publica con AWS Amplify Hosting. Debe ser original, no haber sido publicado antes y quedar accesible durante toda la ventana de evaluación.

## Audiencias

| Audiencia | Qué busca | Qué le damos |
| --- | --- | --- |
| Jurado de AWS (revisión por IA y humana) | Función creativa que funcione, URL viva, tres secciones, documentación de AWS | Portada clara, función creativa con pista visible, enlaces que no se rompen |
| Reclutadores e internships en Chile | Quién es, qué sabe, qué ha construido | Historia breve, stack, proyectos con rol y resultado, contacto directo |
| Compañeros y contactos | Ver trabajo y repositorio | Enlaces a GitHub y a cada proyecto |

## Superficies

| Superficie | Qué optimiza |
| --- | --- |
| Web escritorio | Lectura editorial, casos de estudio en dos columnas, la función creativa con pista visible |
| Web móvil (desde 320px) | Una columna, objetivos táctiles de 44px o más, mismo comportamiento que escritorio |

Una sola superficie técnica: sitio estático en Amplify. Se muestra el mismo componente a ancho teléfono y escritorio; cambia el layout, no la lógica.

## Tono

Seguro, directo y concreto, en español de Chile. Frases con cifras. Un toque de humor está permitido solo dentro de la función creativa.

## Criterios del reto que el sistema debe proteger

| Criterio | Peso | Cómo lo protege el sistema |
| --- | --- | --- |
| Creatividad y memorabilidad | 30% | Reserva un componente con firma para la función creativa y otro para su pista visible |
| Implementación AWS funcionando | 25% | Sin dependencias externas frágiles; enlaces siempre con estado de foco y destino claro |
| Calidad de comunicación | 25% | Plantillas de caso de estudio con rol, decisión y aprendizaje; textos reales |
| Completitud y usabilidad | 20% | Plantilla con las tres secciones obligatorias (Sobre mí, Superpoderes técnicos, Proyectos) y navegación operable con teclado, probada desde 320px |
